# Demo Video Script (90 Seconds)

**Title:** Offline Ofrenda Keeper: Honoring the People We Love, with the Wi-Fi Off  
**Setting:** Laptop screen recording. Wi-Fi status icon clearly visible in the system tray / menu bar throughout the recording.

---

| Time | On Screen | Voiceover / Action |
|---|---|---|
| **0:00 – 0:10** | Open network settings or status tray; turn on **Airplane Mode**. Show Wi-Fi icon crossed out and offline status. Open `http://127.0.0.1:8000`. Show green status badge: *"Running locally. No internet needed"*. | *"This is airplane mode. Everything you will see runs completely on this laptop—no cloud, no API keys, and no data leaving the machine."* |
| **0:10 – 0:25** | **Step 1 & Step 2:** Fill name *"Rosa Hernandez"*, relationship *"Abuela"*, years *1941 to 2023*. Add food chips (*tamales de mole*, *pan de muerto*), drinks (*café de olla*), and songs (*Cielito Lindo*). Click Next. | *"I am making an ofrenda for my fictional grandmother, Rosa. We add her favorite traditional foods, drinks, and the songs she loved."* |
| **0:25 – 0:45** | **Step 3:** Select a portrait photo; instant local preview displays. Click **Record Voice Note**. Speak 5–10 seconds about Rosa baking bread and singing. Click **Stop Recording**. The transcription appears in the editable box via faster-whisper. | *"Whisper, an open-source model running on CPU, turns my voice note into text right on my laptop in seconds. Nothing is sent to a server farm."* |
| **0:45 – 1:05** | **Step 4:** Click **Generate Remembrance**. Notice the *"Lighting the candles..."* loading indicator. A warm, factually grounded 3-paragraph remembrance appears, followed by the rendered three-tier altar preview in the live iframe. | *"A small open model through Ollama writes a gentle, respectful remembrance using only the facts I provided. Notice the flickering candle animations, papel picado garland, and altar offerings."* |
| **1:05 – 1:20** | Switch model in dropdown to `qwen3:1.7b` or alternative model. Click **Regenerate**. Click **Download HTML File** and open the saved single-file HTML directly with `file://` URL in a new browser tab. | *"I can swap models freely. And the result is a single, self-contained HTML file my family owns forever—no subscriptions, no dependencies."* |
| **1:20 – 1:30** | Click **Print or Save as PDF**. Show print preview displaying the full altar layout preserved. Show system tray still in Airplane Mode. | *"Memories of the people we love should never need a server farm."* |
